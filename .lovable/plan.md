# План доработки промпта по замечаниям к урокам 44–85

## Что показали замечания (сгруппировано)

1. **Повторы между уроками одной темы** (63–67, 72–74, 80–84): одни и те же сюжеты, числа и задачи; «новая/изменённая ситуация» не новая; второй урок по теме повторяет первый.
2. **Знания «из будущего» и чужие методы** (48 — корень, 59 — нахождение числа по дроби в контрольной до этой темы, 56 — посторонний способ, 71 — внезапные десятичные дроби, 77 — ситуация из следующего урока, 78 — отношения дробей до их изучения).
3. **Известное подаётся как новое** (51, 55, 64: «откроем новый способ», хотя действие уже изучено; 77: мотивация повторяет прошлый урок как открытие).
4. **Смысл этапов размыт**: «выявление затруднений» не проверяет тему урока (56, 62); «планирование» привязано к одной задаче (47); «усложнённая ситуация» проще прежних (47, 50); самопроверка проверяет не тот этап (46); проблемная ситуация звучит как совет сделать неправильно (45); цели вида «узнать, как называется» (76, 79).
5. **Методика вычислений**: сначала перемножают, потом сокращают; нерациональные способы (57 — не делят сначала на 3; 58 — раскрывают скобки там, где проще сложить); «взаимно обратное» вместо «обратное делителю» (60).
6. **Реалистичность задач**: дробное число деталей в час (63), нет условия одинаковой производительности (78, насосы 82–84), «исторические задачи» без источника (75), сомнительные сюжеты (85).
7. **Согласованность**: в «Содержании» задачи, которых нет в ходе урока (45, 62); контрольная не по своему разделу (59, 71); тема урока теряется (69–70 «дробные выражения»).
8. **Разметка**: вложенные списки вариантов с отступами ломаются при переводе в Word (58); склеенная таблица (49).

## Что изменить

**A. Учебный контекст в запросе**
- Передавать не 2 соседних урока, а весь список пройденных тем до текущего (тема, тип, ключевые понятия) и список будущих тем раздела как «запрещённые».
- Сообщать позицию урока в серии: «урок 2 из 4 по теме …» и что делали предыдущие уроки этой серии.
- Для контрольной передавать только уроки её раздела; задания — строго по ним.

**B. Память о прошлых планах**
- Сохранять краткую выжимку каждого готового плана (сюжеты задач, числа, ключевые примеры, формулировку определения).
- Передавать выжимку предыдущих уроков серии с правилом: не повторять сюжеты и числа, давать новый класс задач, в мотивации опираться на уже сказанное («напоминает»), а не открывать заново.

**C. Правила этапов в промпте**
- Проблемная ситуация: учитель спрашивает «можно ли…», а не предлагает делать неверно.
- Выявление затруднений — только на материале текущей темы.
- Планирование — общий способ действий, а не план одной задачи.
- Изменённая/усложнённая ситуация обязана быть сложнее всех задач предыдущих уроков темы.
- Самопроверка явно указывает, какой этап проверяется.
- Цели формулировать через «для чего нужно», а не «узнать название».
- Если действие уже изучено — не называть его новым способом.

**D. Методические и математические правила**
- Сокращать до умножения; выбирать рациональный способ (делить обе части, сначала вычислять скобку, когда так проще).
- Не использовать понятия, которых ещё нет по программе (корень, десятичные дроби, проценты — по списку пройденного).
- «Число, обратное делителю»; «взаимно обратные» — только о паре.
- Реалистичные ответы (целое число предметов), явные условия (одинаковая производительность), без выдуманных «исторических» фактов — вместо этого «представим себя на месте древних математиков».
- В «Содержании урока» — только задачи из хода урока.

**E. Автоматические проверки в сервисе**
- Запрет вложенных списков с отступом и склеенных строк таблицы.
- Список запрещённых понятий по номеру урока (например, \sqrt, десятичная запятая до их темы).
- Каждая задача из «Содержания» должна встречаться в ходе урока.
- Для контрольной — задания хотя бы по каждой теме раздела.
- Сравнение с выжимкой прошлых уроков серии: повтор чисел и сюжетов — повод для корректирующей генерации.

**F. После доработки**
- Перегенерировать точечно (через ваш ключ, с вашего согласия) самые слабые уроки: 47, 58, 62, 66, 67, 69, 70, 71, 72–74, 81, 83, 84.
